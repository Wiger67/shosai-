# 語法展示

這一章展示 Markdown 的各種語法在 PDF 中的樣子。特殊符號也要正確顯示：#、*、_、$、@、<標籤>、[方括號]、a/b、1+1=2、C:\路徑、"引號"、'單引號'。

## 文字樣式

*斜體*、**粗體**、~~刪除線~~、`行內程式碼`，以及[一個連結](https://nextcloud.com)。
這裡有一個註腳[^1]。

[^1]: 註腳會出現在頁面底部。
